# Lightning Strike (Fabric, Minecraft 26.3)

Sword enchantment. Right-click with an enchanted sword: 10-block yellow particle beam,
damages hostile mobs and other players along it, 10 second cooldown.

Build: `./gradlew build` -> `build/libs/lightning-strike-1.0.0.jar`
Test in dev: `./gradlew runClient`
Give yourself one:
/give @s diamond_sword[enchantments={"lightningstrike:lightning_strike":1}]
